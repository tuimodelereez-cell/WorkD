# work D เวอร์ชันเนทีฟ (Capacitor)

เปลือกแอปแอนดรอยด์ที่ห่อเว็บ work D เดิมไว้ โค้ดเว็บไม่ต้องแก้เลย
แต่ได้ WebView ที่เราคุมเองได้ จึงทำสิ่งที่เบราว์เซอร์ห้ามไว้ได้

## สิ่งที่ได้ทันทีในเวอร์ชันนี้

- **รีลเล่นอัตโนมัติพร้อมเสียงตั้งแต่คลิปแรก** ไม่ต้องแตะหน้าจอก่อน
  (Capacitor ตั้ง `setMediaPlaybackRequiresUserGesture(false)` ให้อยู่แล้ว และแอปตรวจเจอว่ารันบนเนทีฟ
  จึงเปิดเสียงเป็นค่าเริ่มต้น ถ้าผู้ใช้กดปิดเอง ระบบจะจำค่าปิดไว้)
- **วิดีโอคอลขอสิทธิ์กล้องและไมค์แบบเนทีฟ** ประกาศสิทธิ์ไว้ครบใน AndroidManifest แล้ว
- ไอคอนแอปใช้โลโก้ work D ล็อกหน้าจอแนวตั้ง

## สิ่งที่ยังไม่ได้ ต้องทำต่อเป็นสเต็ป 2

| เรื่อง | สถานะตอนนี้ |
| --- | --- |
| แจ้งเตือนสายเข้าตอนปิดแอป | **ใช้ไม่ได้** WebView ไม่มี Web Push ต้องย้ายไป FCM ก่อน |
| โฆษณา AdSense | **ต้องถอดออก** ผิดนโยบายกูเกิลถ้าอยู่ใน WebView ของแอป ต้องเปลี่ยนเป็น AdMob |
| อัดหน้าจอในห้องควบคุม | ใช้ไม่ได้ ต้องเขียนปลั๊กอิน MediaProjection |
| หรี่เสียงรีลเมื่อมีสายเข้า | ยังไม่ได้ทำ ต้องจัดการ audio focus ฝั่งเนทีฟ |

> **อย่าเพิ่งเอาตัวนี้ไปแทนของเดิมที่ผู้ใช้ใช้อยู่** ให้ติดตั้งคู่กันไปก่อนเพื่อทดสอบ
> เพราะตอนนี้ยังเสียความสามารถเรื่องแจ้งเตือนสายเข้าไป

## สิ่งที่ต้องแก้ก่อน build ครั้งแรก

**1. ใส่ลิงก์เว็บจริง** — เปิด `capacitor.config.json` แล้วแทน `https://REPLACE-ME.netlify.app`
ด้วยลิงก์ Netlify ของคุณ · แอปจะโหลดเว็บจากลิงก์นี้ แปลว่า **แก้เว็บแล้วลากขึ้น Netlify ทับ
ผู้ใช้ได้ของใหม่ทันทีเหมือนเดิม ไม่ต้อง build APK ใหม่** เก็บวิธีทำงานแบบที่คุ้นไว้ครบ

**2. ตัดสินใจเรื่องชื่อแพ็กเกจ** — ตอนนี้ตั้งไว้เป็น `app.workd.mobile`
- ถ้าอยากให้คนที่ลง APK เดิม (TWA) **อัปเดตทับได้** ต้องเปลี่ยนให้ตรงกับชื่อแพ็กเกจเดิม
  และเซ็นด้วย keystore เดิมจาก `signing-key-info.txt`
- ถ้าใช้ชื่อใหม่ ทุกคนต้องถอนแอปเดิมแล้วติดตั้งใหม่

เปลี่ยนที่ `capacitor.config.json` (`appId`), `android/app/build.gradle` (`namespace`, `applicationId`),
`android/app/src/main/res/values/strings.xml` และชื่อโฟลเดอร์ใน `android/app/src/main/java/`

## เอาโปรเจกต์ขึ้น GitHub จากมือถือ

GitHub จะ build APK ให้ฟรี ไม่ต้องมีคอมพิวเตอร์ แต่ต้องเอาโค้ดขึ้นไปก่อน เลือกทางใดทางหนึ่ง

### ทาง ก — Termux (ทำบนเครื่องอย่างเดียว)

1. ลง **Termux** จาก F-Droid (อย่าลงจาก Play Store เพราะตัวนั้นเก่า)
2. `pkg install git unzip -y`
3. แตกไฟล์ zip นี้ไว้ แล้ว `cd` เข้าโฟลเดอร์ `workd-native`
4. สร้าง repo เปล่าบน github.com (ตั้งเป็น Private ได้)
5. ```
   git init && git add -A
   git commit -m "work D native"
   git branch -M main
   git remote add origin https://github.com/<ชื่อคุณ>/<ชื่อ repo>.git
   git push -u origin main
   ```
   ตอนถาม password ให้ใส่ **Personal Access Token** ไม่ใช่รหัสผ่านบัญชี

### ทาง ข — GitHub Codespaces (ทำในเบราว์เซอร์)

1. สร้าง repo เปล่าบน github.com
2. กด **Code → Codespaces → Create codespace**
3. ลากไฟล์ zip นี้เข้าไปในแถบไฟล์ด้านซ้าย แล้วสั่ง `unzip workd-native.zip`
4. `git add -A && git commit -m "work D native" && git push`

## ได้ไฟล์ APK มายังไง

1. push ขึ้นไปแล้ว GitHub จะเริ่ม build เอง (หรือกดเองที่แท็บ **Actions → build android apk → Run workflow**)
2. รอราว 5-8 นาที
3. เข้าไปในรอบที่ build เสร็จ เลื่อนลงล่างสุด ดาวน์โหลด **workd-apk**
4. แตก zip จะได้ไฟล์ `app-debug.apk` ติดตั้งได้เลย

**ถ้าจะทำตัวจริงที่เซ็นแล้ว** ใส่ Secrets ใน repo (Settings → Secrets and variables → Actions)
- `KEYSTORE_BASE64` — ไฟล์ keystore แปลงเป็น base64 (`base64 -w0 workd.keystore`)
- `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`

ถ้าไม่ใส่ ระบบจะ build แค่ตัวทดสอบให้ ไม่ error

## ต้องทดสอบอะไรบ้าง

ติดตั้ง APK แล้วไล่เช็กตามนี้ ข้อที่ทำเครื่องหมาย ⚠️ คือข้อที่คาดว่าจะยังไม่ผ่าน

### ส่วนที่เป็นเป้าหมายของรอบนี้

1. **เปิดแอป → ไปหน้ารีล** · คลิปต้องเล่นเอง **พร้อมเสียงทันที** โดยไม่ต้องแตะอะไรก่อน
   และต้องไม่มีป้าย "แตะเพื่อเปิดเสียง" ขึ้นมา — นี่คือข้อที่สำคัญที่สุดของรอบนี้
2. **กดปุ่มลำโพงให้ปิดเสียง แล้วปิดแอป เปิดใหม่** · ต้องยังเงียบอยู่ ไม่กลับมาดังเอง
3. **เลื่อนรีลไปมา** · ต้องมีเสียงแค่คลิปที่อยู่ในจอ ไม่ซ้อนกันหลายคลิป

### ส่วนที่ต้องไม่พังจากของเดิม

4. **เข้าสู่ระบบ** · ล็อกอิน Supabase ต้องผ่านเหมือนเปิดในเบราว์เซอร์
5. **โพสต์ที่มีรูปหรือวิดีโอ** · ปุ่มเลือกไฟล์ต้องเปิดแกลเลอรีของเครื่องได้
6. **อัปโหลดรูปโปรไฟล์และรูปหน้าปก** · ต้องขึ้นจริงและเห็นทุกหน้า
7. **แชท** · ส่งข้อความสองเครื่องต้องเด้งหากัน และแถบแจ้งเตือนในแอปต้องขึ้น
8. **วิดีโอคอล** · เครื่องต้องถามสิทธิ์กล้องกับไมค์ครั้งแรก ตอบอนุญาตแล้วต้อง
   - เห็นกล้องตัวเองมุมขวาบน
   - แตะจอเล็กแล้วสลับจอได้
   - กดปุ่มกล้องหน้า/กล้องหลังแล้วอีกฝ่ายเห็นภาพเปลี่ยน
   - ภาพไม่กระพริบ
9. **เช็กชื่อเข้างาน / ห้องควบคุม** · เปิดได้ไหม ดูว่าพังตรงไหน
10. **ปุ่มย้อนกลับของเครื่อง** · กดแล้วต้องถอยกลับหน้าก่อนหน้า ไม่ใช่ปิดแอปทันที

### ส่วนที่รู้อยู่แล้วว่าจะไม่ผ่าน

11. ⚠️ **สายเข้าตอนปิดแอป** · จะไม่ขึ้น เพราะยังไม่ได้ย้ายไป FCM — เป็นงานสเต็ป 2
12. ⚠️ **โฆษณา** · จะไม่ขึ้นหรือขึ้นแล้วผิดนโยบาย ต้องเปลี่ยนเป็น AdMob
13. ⚠️ **อัดหน้าจอในห้องควบคุม** · จะใช้ไม่ได้ ต้องมีปลั๊กอินเนทีฟ

**จดไว้ว่าข้อไหนพังและพังยังไง** แล้วบอกมา จะได้ไล่แก้เป็นรอบ ๆ
ถ้า build ไม่ผ่านตั้งแต่แรก ให้ copy ข้อความ error จากแท็บ Actions มาให้ดู
